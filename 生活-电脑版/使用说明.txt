《生活》电脑版 · 使用说明
============================================================

一、怎么开始玩
  1. 把整个「生活-电脑版」文件夹解压到任意位置（放桌面也行）。
  2. 双击文件夹里的「启动游戏.bat」。
  3. 游戏会以「应用窗口」打开：没有地址栏、没有浏览器工具栏，
     看上去就是一个独立的桌面小程序。窗口大小约 1120×800，可随意拉伸。
  4. 关掉这个窗口，游戏就退出了，进度已经自动存好。

二、为什么文件这么小
  游戏本身是一个单文件网页（生活.html）：CSS、脚本、存档逻辑全部内嵌，
  不联网、不加载任何外部资源、不需要安装。
  启动器会直接用你电脑上已有的 Edge / Chrome / Brave，以「应用窗口」模式打开它，
  所以既不用装额外软件，也不用下载任何东西。

三、存档
  进度保存在本机浏览器里（同一台电脑、同一个浏览器），关掉再进能接着玩。
  想从头开始：点游戏标题旁的「重开」按钮即可。
  想清空存档：在游戏里重开一局，或清除该浏览器的站点数据。

四、常见问题
  · 双击后没有任何反应 / 一闪而过？
      → 说明既没找到 Edge / Chrome，也没能调用默认浏览器。先确认文件已解压完整；
        再确认电脑上装了 Edge 或 Chrome（Win10/11 一般都自带 Edge）。
  · 打开后有地址栏，不像独立程序？
      → 说明电脑上没找到 Edge / Chrome，走了「默认浏览器」的退路。装一个 Edge 或 Chrome，
        再双击「启动游戏.bat」即可获得独立窗口效果。
  · 嫌 .bat 难看 / 想要桌面图标？
      → 右键「启动游戏.bat」→ 发送到 → 桌面快捷方式。
        之后双击桌面那个快捷方式就行（图标可右键 → 属性 → 更改图标自行替换）。
  · 能不能不用启动器？
      → 可以，直接双击「生活.html」用任意浏览器打开，游戏内容完全一样。

五、文件清单
  生活.html        —— 游戏本体（单文件，可单独双击打开）
  启动游戏.bat     —— 双击即玩的启动器（推荐入口）
  使用说明.txt     —— 本说明
